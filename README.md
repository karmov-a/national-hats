# Наследие — кабардинские головные уборы

Витрина из шести моделей с фотографиями, без цен. Next.js 15, React 19, TypeScript.

## Локальный запуск

Требуется Node.js 22 LTS.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Проверка перед публикацией

```bash
npm run build
npm start
```

## Публикация на Vercel

1. Войдите в Vercel через GitHub.
2. Выберите Add New → Project и импортируйте `karmov-a/national-hats`.
3. Framework Preset: Next.js, Root Directory: корень репозитория. Остальные параметры стандартные.
4. Для публичной витрины переменные окружения не требуются. Нажмите Deploy.
5. После сборки используйте адрес из раздела Domains. Обновления ветки main публикуются автоматически.

Для коммерческого сайта выберите подходящий коммерческий тариф хостинга.

## Фотографии и каталог

Фотографии лежат в `public/img`. Названия, оттенки и соответствие фотографий моделям задаются в `lib/catalog.ts`.

В проекте также сохранён прежний модуль администрирования (`app/admin`, Supabase, NextAuth). Он не управляет текущим каталогом витрины. Для отдельного подключения этого модуля нужны реальные настройки Supabase и NextAuth; локальный `.env` не публикуется.
